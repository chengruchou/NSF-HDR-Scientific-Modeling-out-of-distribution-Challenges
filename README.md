# NSF-HDR-Scientific-Modeling-out-of-distribution-Challenges

This repository contains three final submission tracks for scientific modeling tasks:

- `Final_Submission/Predicting_Coastal_Flooding_Events`: Predicts coastal flooding events using machine learning with feature engineering and boosting-based methods.
- `Final_Submission/Neural_Forecasting`: Forecasts multi-step neural time-series signals with a Transformer-based neural forecasting pipeline.
- `Final_Submission/Beetles_as_Sentinel_Taxa`: Predicts SPEI-related climate indicators from beetle event images using an event-level MIL vision model.
